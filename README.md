A lightweight LiDAR-Inertial Odometry system based on ROS2 Humble.

Features:

- FAST-LIO2 style Iterated ESKF backend
- ikd-Tree local map
- ROS2 Humble support
- Gazebo simulation with Livox MID360 and RealSense D435
- Real-world UAV experiments
